# THEME 05 — Analytics et sources agrégées

- **Message** : une vue d'ensemble de tout le marché, toutes les sources dans un seul tableau de bord.
- **Cible** : revendeurs, investisseurs, recruteurs (démonstration technique).
- **Écrans** : Analytics (héro violet, compteurs, barres de répartition par source), puis assemblage final des interfaces.
- **Moment héroïque** : les compteurs montent, les barres de répartition se remplissent, tous les écrans s'assemblent en un seul objet dans l'espace.
- **Accroche texte** : « Des milliers d'annonces. Une seule vue. »
- **Durée** : 15–20 s. **Format** : 1080×1920.
- **Son** : montée continue, impact doux sur l'assemblage, signature logo.
- **À vérifier** : tous les chiffres (annonces, sources, taux) à confirmer le jour du rendu (voir brand).
