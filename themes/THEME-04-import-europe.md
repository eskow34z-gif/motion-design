# THEME 04 — Import Europe

- **Message** : accéder aux annonces d'autres pays européens (AutoScout24 ES/IT/DE) dans la même interface.
- **Cible** : revendeurs et importateurs.
- **Écrans** : Véhicules, onglet Import EU, badges AUTOSCOUT24 par pays.
- **Moment héroïque** : les annonces de plusieurs pays convergent dans un seul flux (le sillage les rassemble), le meilleur écart de prix ressort.
- **Accroche texte** : « Toute l'Europe d'occasion, dans un seul écran. »
- **Durée** : 15–20 s. **Format** : 1080×1920.
- **Son** : un tick par pays, accord qui se résout quand le flux est unifié.
- **À vérifier** : pays réellement couverts, et ne pas citer de règle fiscale (ex. TVA sur marge) sans validation.
